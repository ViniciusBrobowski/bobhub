# Roadmap

## Project Vision

Transformar o BobHub em uma plataforma de aprendizado prático voltada para Infraestrutura, Observabilidade, Automação e DevOps.

O objetivo é utilizar o ambiente para desenvolver competências técnicas aplicadas em cenários corporativos modernos.
